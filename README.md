# Pablo Is An Artisan
## Scenario
In this program, the user acts as a fellow artisan named "Pablo" who is a fashion designer. The main objective of the simulation is for the user to create a nice outfit using a collection of 8 items/sprites and attempting to earn the most money from retail prices and commission as possible.
